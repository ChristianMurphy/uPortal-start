# Accepted uses of APIs that Tomcat 11 (Servlet 6.0/6.1, Pages 4.0, EL 6.0) removed, found in the
# overlay WARs by 'removedApiScan' (RemovedApiScanPlugin).  An unaccepted use fails 'check' and
# 'tomcatDeploy';  each overlay's build/reports/removed-api.txt lists every use.
#
#   webapp | location | source | api | reason
#
# Globs:  * matches anything, / included.  'location' is a jar name, WEB-INF/classes or a JSP path;
# 'source' the referencing class (or the JSP line);  'api' a class, or owner#member.  Accept a use
# only when it cannot be reached on Tomcat 11, and say why:  a class that is never loaded, a method
# that only overrides or forwards to the removed one.  Fix it instead when it can be reached.

# --- Overrides and forwarders ------------------------------------------------------------------
# A wrapper or proxy that implements or overrides a removed method and forwards it to the wrapped
# object (or to super).  On Tomcat 11 the interface no longer declares the method, so nothing calls
# it;  the class itself loads and works.  They go when each library moves to Servlet 6 (uPortal's
# own two in P6-1;  the libraries with their portlets, MOD-D13).
* | spring-web-*.jar | org/springframework/web/util/ContentCachingResponseWrapper* | javax/servlet/http/HttpServletResponseWrapper#setStatus(ILjava/lang/String;)V | forwarder:  overrides setStatus(int,String) and calls super
* | spring-web-*.jar | org/springframework/web/filter/ShallowEtagHeaderFilter* | javax/servlet/http/HttpServletResponseWrapper#setStatus(ILjava/lang/String;)V | forwarder:  its response wrapper overrides setStatus(int,String) and calls super
* | spring-security-web-*.jar | org/springframework/security/web/context/SaveContextOnUpdateOrErrorResponseWrapper | javax/servlet/http/HttpServletResponseWrapper#encode*Url(Ljava/lang/String;)Ljava/lang/String; | forwarder:  overrides encodeUrl/encodeRedirectUrl and calls super
* | uPortal-rendering-*.jar | org/apereo/portal/portlet/rendering/worker/Guarding* | javax/servlet/* | forwarder:  uPortal's guarding request/response wrappers override every method;  the Servlet 6 source migration (P6-1) deletes these overrides
* | uPortal-utils-core-*.jar | org/apereo/portal/utils/web/AbstractHttpServletResponseWrapper | javax/servlet/http/HttpServletResponse#* | forwarder:  delegates every HttpServletResponse method;  deleted by the Servlet 6 source migration (P6-1)
cas | esapi-*.jar | org/owasp/esapi/filters/SecurityWrapperRequest | javax/servlet/* | forwarder:  ESAPI's request wrapper forwards getRealPath/isRequestedSessionIdFromUrl
esup-filemanager | jackrabbit-webdav-*.jar | org/apache/jackrabbit/webdav/Webdav*Impl | javax/servlet/* | forwarder:  WebdavRequestImpl/WebdavResponseImpl forward every method to the wrapped request/response
CalendarPortlet | java-support-*.jar | net/shibboleth/utilities/java/support/net/ThreadLocalHttpServlet*Proxy | javax/servlet/* | forwarder:  thread-local request/response proxies forward every method
