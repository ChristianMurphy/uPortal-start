# The full matrix before a landing (`-ci-prelanding`)

The note for this topic is in uPortal, at `docs/developer/modernization/notes/ci-prelanding.md`
on the branch of the same name. It has the job matrix before and after, the design of the
staging check, its limits, the proof runs and the proposed LOG rows.

In this repository the topic changes the workflows, `.github/scripts/staged.sh` with its table
test, `.github/scripts/gindex-changes.sh` and `docs/developer/ci-jobs.md`, which describes
staging branches and the staging check for readers of this repository.
